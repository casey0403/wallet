동시성 보장

  • Redis lock key는 wallet:withdraw:{walletId} 단위로 잡습니다.
  • DB 최종 방어선은 UPDATE wallets SET balance = balance - :amount, version = version + 1 WHERE id = :walletId AND version = :version AND balance >= :amount AND wallet_status = 'ACTIVE'입니다.
  • Redis lock이 만료되거나 중복 실행되어도 조건부 update가 overdraft와 lost update를 막습니다.

멱등성 보장

  • idempotency_requests는 wallet_id, idempotency_key unique constraint로 중복 요청을 막습니다.
  • 같은 key인데 request_hash가 다르면 409 conflict로 처리합니다.
  • 성공/실패 모두 response_snapshot에 저장해서 재요청 시 동일 응답을 반환합니다.
